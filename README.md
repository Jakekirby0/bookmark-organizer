# Bookmark Organizer

A personal application for organizing website links.

## Features

- Save bookmarks
- Search links
- Open or remove bookmarks

## How to Use

Enter a website name and valid URL.

## Technologies

- HTML
- CSS
- JavaScript

## Running Locally

Open `index.html` in a modern web browser.
## Manual Testing Checklist

- [ ] Save a valid HTTP or HTTPS bookmark.
- [ ] Search the saved bookmark by its title.
- [ ] Reject malformed URLs and remove a saved entry.
